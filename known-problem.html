    How to flag a page

    1. Write a short JSON-LD report (see sample shape below) and host it under /problems/ or any HTTPS URL this site can fetch.
    2. Link the broken or doubtful page to this view with the report in the query string, for example:
      /known-problem.html?report=/problems/your-issue.jsonld
    3. Optionally add &page= with the affected URL if it is not already inside the JSON-LD.

    Example with the sample file: /known-problem.html?report=/problems/sample.jsonld
